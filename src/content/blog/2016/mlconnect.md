MLConnect lets you connect your Android device to Matlab running on a PC.

The following two videos will give you an overview of how to use MLConnect. Scroll to the bottom of the page for Matlab Code downloads.

The following files contain all the Matlab Code that you will need to understand and make use of MLConnect:

-   [MLCDemo](/files/legacy/media/mlconnect/MLCDemoV2.0.zip): Start runDemo.m to learn about all the functions of MlConnect
-   [MLCFCServer](/files/legacy/media/mlconnect/MLCFCServer2v0.zip): Start runFullControlServer.m to remotely control a Matlab session
-   [MLCAccelerometer](/files/legacy/media/mlconnect/MLCAccelerometerV2.0.zip)
-   [MLCMatlabAPI](/files/legacy/media/mlconnect/MLCMatlabAPIV2.0.zip): The bare bones
